6. Activités sur votre compte
Cet historique de votre compte recense toutes les transactions effectuées via la boutique Nintendo DSi, comme le téléchargement de logiciels ou l’achat de Nintendo DSi Points. Pour afficher la liste des activités sur votre compte, touchez PARAMETRES dans le menu principal de la boutique Nintendo DSi, puis sélectionnez VOTRE COMPTE.

Touchez le titre d'un logiciel pour afficher des détails le concernant. Si vous avez effacé un logiciel, vous pouvez le télécharger à nouveau sans dépenser de Nintendo DSi Points. Touchez CARTE BANCAIRE pour afficher les détails d'une transaction.

Pour savoir comment effacer votre compte, reportez-vous à la section 8 "Paramètres/Autres".
